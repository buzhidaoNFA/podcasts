## 核心摘要

本期主持人 **孟恭**（夢宮）獨自開講，無嘉賓。內容分兩大塊：前半段是他近期放慢生活步調、練習正念/內觀/禪修的感悟，以及如何意外改善長年下背痛；後半段進入市場分析，核心觀點如下：

**市場總體判斷：**
- 孟恭自爆目前約 **90% 資金鎖在處置股（含20分鐘處置）**，因券商收緊不限用途借款額度，已無法加碼，「沒事做」階段。他認為這是「老天幫你做風控」。
- 台股處於 **「非常漂亮的多頭」**，百花齊放，資金充沛，ODM/OEM、被動元件、軟體股輪動上攻。

**被動元件：**
- MLCC 與鋁電容（SPCAP、OSCON、牛角電容）從「成本驅動漲價」轉為 **「需求驅動漲價」**。公司派一兩個月前還保守，現在已改口。
- 江海（鋁電容）收到的內部 MEMO 指出全球缺口高達 **20% 以上**，所有產能加起來都不夠，後續持續漲價。
- 市場目前只聚焦 MLCC，但 **鋁電容/電感/電阻的缺口同樣嚴重**，屬於「房間裡的大象」。

**老 AI / ODM 復活：**
- 資金大幅撤出 ODM/EMS 後，近期重新回流。鴻海、廣達鎖漲停，陳泰銘（國巨）剛成為台灣首富，與鴻海/廣達老闆身家接近，可能出現「首富賽跑」。
- 孟恭認為這不是因為 Dario 或單一公司成績超預期，而是 **資金輪動的自然結果**——「不要在東西不好的時候亂 diss，也不要在東西好的時候才追」。

**軟體股大爆發：**
- Dario（Anthropic）和 Sam Altman（OpenAI）不約而同轉變論述，從「AI 末日論」轉向「AI 改善效率、創造更多就業」。
- 孟恭堅定站 **黃仁勳（黃雲勳）一派**：AI 是來幫人，不是取代人。
- Salesforce 進行「歷史級別回購」、ServiceNow 老闆強硬表態、Okta / Snowflake 財報超預期，軟體股進入「Sexy Back Zone」。
- IGV ETF（軟體 ETF）拉出高斜率上漲，視為資金明確表態。

**AI 產業趨勢（精緻化時代）：**
- 模型訓練基於公開資料，通用性高，**邊際效應遞減**；未來勝負手是 **「誰掌握特有資料/專有資料/封閉資料」**。
- **業務能力與商務能力** 將凌駕於模型能力之上。企業部署 AI 需要「可規則性」（問責），因此 SI / 整合商 / 在地服務商價值重估。
- AI 進入「精緻化」階段：過去是 Fast-Full 量產鋪出去，現在要解決角色延續、版權、法遵、後續規劃等問題。

## 容易被忽略但有价值的信息

1. **券商額度控管成為隱形風險**：孟恭提到券商不收不限用途借款，導致他無法加碼。這意味著大量槓桿資金其實已被「鎖死」，若市場回檔，這些資金無法即時停損或反手，反而可能在極端情況造成流動性斷層。

2. **公司派自己賣股票**：孟恭指出，很多台灣公司派在 AI 行情初期「不相信」，把手上的持股賣掉，甚至賣到「隨時可以被 takeover」的程度。這說明這波漲勢的籌碼結構可能比我們想像的更集中（外部人手上）。

3. **「房間裡的大象」——鋁電容缺口 20%**：市場熱度全在 MLCC，但鋁電容（SPCAP、OSCON、牛角電容）缺口高達 20% 以上，且擴產需時（2027 年底才完工），這段時間的供需失衡被嚴重低估。

4. **AI 論述轉向的政治壓力**：Dario 和 Sam Altman 轉向不是因為良心發現，而是因為「AI 末日論」引發政治人物和年輕選民反彈，監管壓力大增。這暗示 AI 監管風險已從「科技圈討論」進入「實體政治圈」。

5. **軟體公司從 Seat-based 轉 Token-based 計費**：過往 SaaS 公司的商業模式轉換陣痛（股價崩殺、財報難看）是正常現象，但只要轉過去，營收與獲利會「增速跳升」。這是理解近期軟體股財報爆發的關鍵背景。

6. **Google TPU as a Service 的潛在邏輯**：Google 與黑石合作推出 TPU 出租，不是為了擴展自有 Cloud，而是因為很多企業「不想把資料給 Google」。這點意味著 **「資料主權」與「可規則性」** 正在重塑雲端/AI 基礎設施的競爭格局。

## 直观地可以 bullish / bearish on 什么

**Bullish：**
- **被動元件（鋁電容 > MLCC）**：需求驅動漲價，缺口 20%+，擴產遠水救不了近火。孟恭明確表示這波從成本驅動轉為需求驅動，後者更持久。
- **軟體股 / SaaS**：IGV ETF 表態、Salesforce 歷史級回購、ServiceNow / Okta / Snowflake 財報超預期。AI 從「威脅」轉為「加分項」。
- **老 AI / ODM / OEM（鴻海、廣達、國巨相關供應鏈）**：資金輪動回流，基本面（營收+獲利）持續強勁，陳泰銘成首富象徵資金認可。
- **台股整體**：孟恭認為「滿地都是好東西」，資金充沛，百花齊放，只要沒有瘋狂升息或國際事件，多頭延續。
- **AI 整合商 / SI / 在地服務商**：掌握「可規則性」與「企業資料入口」的價值，將在「精緻化 AI 時代」獲得議價權。

**Bearish：**
- **「AI 末日論」相關的極端行銷論述**：政治反彈與監管壓力上升，繼續吹噓「AI 取代所有人」的廠商會被修理。
- **高融資槓桿的散戶**：孟恭提醒融資增加速度「超級快」，很多人「拿命去搏」，這是後市不穩定因子。
- **單一硬體/晶圓代工中的落後者**：「不是說 AI 好，每個晶圓代工業者都好」——孟恭明確區分，有些 server 廠「躺在地上」，不能因族群狂熱而盲目買入。

## 隐含地可以 bullish / bearish on 什么

**隐含 Bullish：**
- **資料資產（Data Assets）與資料主權**：孟恭強調「誰掌握特有資料，誰是贏家」。這意味著擁有大量封閉/付費/專有資料的產業——如醫療、金融、法律、工業製造——在導入 AI 後的競爭優勢將被重估。對應的「資料基礎建設」（Data Infrastructure）與「隱私計算/資料安全」也是隱性受益者。
- **企業級 AI 部署（Enterprise AI / B2B AI）**：孟恭認為消費端 AI 工具（如 Perplexity）已經證明「業務能力 > 模型能力」，這個邏輯在企業端會更極端——因為企業需要「可規則性」。這利好 **專注法遵、在地服務、能簽 SLA 的 B2B AI 廠商**，而非單純賣 API 的模型公司。
- **Token-based 計費轉型成功的 SaaS**：孟恭提到過去軟體公司從 Seat-based 轉 Token-based 會經歷陣痛，但只要轉型成功，營收會「增速跳升」。這暗示 **已完成計費模式轉型的 SaaS 公司**，後續財報可能還有驚喜。
- **「精緻化 AI」周邊（版權管理、內容審查、AI 治理、RAG 基礎設施）**：孟恭強調 AI 進入精緻化時代，要解決角色延續、版權、法遵、幻覺問題。這些「問題」本身就是商機——**AI 治理（AI Governance）與內容安全** 將成為隱性高增長賽道。

**隐含 Bearish：**
- **純模型公司（Pure-play Model Providers）的長期議價力**：孟恭說「用戶不在意你背後用哪個模型，只要 deliver 結果」。這暗示模型層有「商品化」風險，OpenAI / Anthropic 等若無法鎖定企業級資料與業務場景，長期可能淪為「上游供應商」而非「價值捕獲者」。
- **過度依賴「通用公開資料」的 AI 應用**：隨著邊際效應遞減，基於公開資料訓練的通用模型差異化將縮小，應用層若無法取得「封閉資料」授權，護城河會變薄。
- **台灣散戶融資盤**：孟恭說「融資增加速度超級快」「拿命去搏」。這是個警訊——當市場進入「沒事做」階段（籌碼鎖死），任何突發回檔可能引發連鎖斷頭，而非健康換手。
- **監管風險被低估的 AI 概念股**：孟恭點出政治人物已因「AI 末日論」而開始施壓。若未來出現重大 AI 醜聞（如深度偽造、選舉操控、就業衝擊），監管可能突然收緊，對估值過高的 AI 概念股構成系統性風險。

## 可能利好/利空的股票

**利好（Bullish）：**

- **國巨（2327）** / **華新科（2492）** / **禾伸堂（3026）** — MLCC 與被動元件領導廠，從成本驅動轉為需求驅動漲價，孟恭明確點名「缺貨會持續」。國巨陳泰銘剛成台灣首富，象徵資金對族群龍頭的極度認可。

- **江海（.component）** — 孟恭直接提到收到江海內部 MEMO，鋁電容（SPCAP、OSCON、牛角電容）全球缺口 20%+。鋁電容是被市場忽略但缺口更嚴重的「房間裡的大象」。

- **鴻海（2317）** / **廣達（2382）** / **緯創（3231）** / **英業達（2356）** — 老 AI / ODM 族群資金回流，孟恭認為「營收跟獲利一直都有，只是市場不喜歡」，現在資金重新擁抱，股價鎖漲停。

- **台積電（2330）** / **日月光（3711）** — 前端製程持續滿載，後段封測也受惠 AI 需求。孟恭提到「承受製程的東西後面也噴上去」，台積電釋出的 legacy 產能也讓後段廠商受惠。

- **Salesforce（CRM）** / **ServiceNow（NOW）** / **Snowflake（SNOW）** / **Okta（OKTA）** — 軟體股「Sexy Back Zone」，業績證明 AI 是加分而非扣分。Salesforce 歷史級回購顯示公司派強烈信心。

- **奇鋐（3017）** / **雙鴻（3324）** / **建準（2421）** — 散熱族群，隨著 AI server 持續出貨，散熱規格升級，需求與被動元件類似是「硬缺口」。

- **Perplexity（未上市）概念映射** — 孟恭以 Perplexity Computer 為例，說明「業務能力 > 模型能力」。在台股中，具備類似「多模型整合+企業資料接入」能力的 **AI 軟體服務商 / SI 廠商** 可能間接受惠（如叡揚、資通、零壹等，但需個別檢視業務轉型進度）。

- **奇偶（3356）** / **慧友（5484）** / **安防/資料治理相關** — AI 精緻化時代需要「可規則性」，涉及資料安全、內容審查、法遵工具的廠商，雖然孟恭未直接點名，但邏輯上屬於隱性受益。

**利空（Bearish）：**

- **過度行銷「AI 末日論」的純模型概念** — 如未上市的一級市場 AI 公司，或二級市場中純粹炒作「取代人類」敘事的概念股。孟恭指出政治與輿論反彈已開始，這類論述會招來監管。

- **未轉型 Token-based 計費的傳統 SaaS** — 孟恭明確說「只要可以轉出來的，特別是創辦人還在裡面的，後面都有機會」，反向意味著 **轉型不順、創辦人離開、仍死守 Seat-based 的舊軟體公司**，將持續被邊緣化。

- **高融資、高槓桿的散戶集中標的** — 孟恭觀察到「融資增加速度超級快」。歷史經驗顯示，當融資餘額與大盤同步創高，任何突發回檔會引發斷頭賣壓。這不是特定個股，而是**高融資比率的熱門股**（如部分處置股、飆股）的系統性風險。

- **族群內的落後者** — 孟恭反覆強調「不是說 AI 好，每個晶圓代工都好；不是說 server 好，每個 server 廠都好」。在 ODM、被動元件、軟體股全面上漲時，**基本面沒有跟上、純粹蹭題材的跟風股**，後續輪動時會最先被資金拋棄。
