## 1. 核心摘要

**本期嘉宾**：无。孟耿单人主持， listeners 通过留言提问互动。

本期结构不按时间线，按投资逻辑权重分三块：

### 一、被动元件——从「补涨」升级为「台股主角」

孟耿花了本期最大篇幅论证被动元件的超级周期。MLCC 最缺的是高规 47UF（国巨目前只能做到一半的 22UF），Murata、Samsung 主导高规供应；台厂（国巨、华新科、立隆电、金山、信昌电等）吃的是**「排擠效应」**——国际大厂往 AI 高规走，低规产能退出，台厂承接转移。

更被市场忽略的是**铝电容**：Panasonic 要退出 OS（固态电容），Nippon Chemicon 承接但产能不够，已启动涨价。他直接打脸市场主流论述：「被动元件扩产容易所以不会缺」是错的，VIA Rubin 放量后颗数暴增，交期只会持续拉长，Power 厂已经提前半年在包产能。

### 二、Legacy 与成熟制程的「真假涨价」

孟耿把涨价拆成**「成本驱动」**和**「需求驱动」**两种。

- **世界先进**新加坡新厂被客户整厂包走 → **真需求**
- 多数消费性 Legacy IC（ddIC 等）的涨价 → 只是上游（德州仪器、罗姆）涨价后的**成本传导**，终端春燕并没有回来
- **汉堂** Q1 毛利意外没往下走，但股价不动——市场对「成本驱动涨价」的持续性存疑

### 三、大盘处于「该涨不涨」的微妙状态

台股从 33,000 喷到 42,000，现在回 41,300，今年只跌 1% 多。孟耿观察到前几天**「点一些东西发现点不动」**——这是微观结构恶化的信号。强势族群（IC design、散热）开始集体转弱，他判断这是修正前兆。

**策略建议**：
- 没部位的人不要追高，等像样回调
- 有部位的人把资金往「古阿康」（10 倍 PE 的大型防守股，如台積電）放，做高低配

### 场外彩蛋：红酒投资哲学

孟耿用 Wine Searcher 按 price tag 买酒，建立大量样本，从低价喝到高价，找到「自己的味蕾喜欢什么」。这跟他做股票的逻辑完全一致：

> *「价格跳最高的，一定有它的道理，老子先买再研究。」*

## 2. 容易被忽略但有价值的信息

- **Power 厂已开始包下被动元件产能**：孟耿提到「Power 厂这边他们有去包产能，直接找被动元件厂把产能包下来」，这是需求端在提前锁定供给，意味着缺料不是假想。

- **日本被动元件厂的「营收衰退但股价喷出」悖论**：Nichicon 等营收增幅平平甚至衰退，但股价「喷到外太空」，因为产品组合转向高规，货利（获利）持续改善。投资人如果只看营收数字会错过全貌。

- **Panasonic 退出 OS（固态电容）**：Nippon Chemicon 承接但产能不足，已发起涨价。这是低规料退出 + 产能缺口的双重挤压。

- **DDR4/DDR5 涨幅曾跑赢 HBM**：记忆体不只是 HBM 的天下，低规记忆体在特定时间段的涨幅甚至超过最高阶产品——类似逻辑可能发生在被动元件的低规料。

- **「点不动」的市场微观信号**：孟耿透露前几天尝试点某些族群，发现「该涨不涨」，这是专业交易员判断修正的前置指标，比技术指标更前置。

- **高通本轮喷发的真实驱动**：孟耿明确排除 AIPC 和 Cloud 叙事，认为是 AI infrastructure / ASIC 相关，跟市场主流解释不同。

## 4. 隐含地可以 Bullish / Bearish on 什么

### 隐含 Bullish

- **光通讯（台股）**：美股光通不断创新髙，台股软趴趴。孟耿解释是因为「台湾题材下太多、百花齐放、资金有限」，但如果美股持续强，台股光通「又再一次醒过来」的概率极高——这是一个补涨赔率。

- **CPU Socket 供应链**：听众提到「家责（家登）」，孟耿确认这是 CPU 外溢题材，持续看好。

- **MCU / 新唐**：2 年前就讲过做进 Google + 微软，现在 MCU 业绩改善确实发生，只是市场换个故事重新炒。

- **半导体检测设备（惠特、均豪）**：听众 portfolio 里有，孟耿未反驳，且归类为「有逻辑的交易者仓位」。

- **防守性的大型股（台積電、联发科）**：孟耿自己把部位调到「台積跟发哥」，暗示在震荡期「大而美」是资金避风港。

- **高通 (QCOM) - AI Infrastructure 叙事**：孟耿认为本轮喷发与 AIPC/Cloud 无关，而是 AI infra / ASIC 芯片。若市场重新定价其 datacenter 地位，估值有重构空间。

### 隐含 Bearish

- **散热族群**：孟耿明确说「散热再转弱」，且提到散热传闻「不是小作文是消息」，NV 研发与量产是两条线，量产若赶不上只是延到下一代，但股价会先杀一波大的。

- **IC Design（集体）**：「过去很强的 IC design 最近开始集体转弱」——这是一个族群级别的逆风信号。

- **纯中小 / 题材炒作**：孟耿提到第一波金刚会消息出来时中小直接死掉，现在虽然部分复活，但只要大盘震荡，「资金可能回流大型股」。

- **AIPC 终端品牌/芯片（非高通）**：孟耿以亲身使用经验认定早期 AIPC「跟垃圾没有两样」、「超烂」，用「小画家」嘲讽早期 AIPC 的伪需求。这对 AIPC 纯概念标的是毒性评价。
